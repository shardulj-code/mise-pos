## ⚡ 60-Second Quick Start

### 1. Run on Windows Computer / Laptop (Counter / Manager)
Double-click `Start-Mise-Desktop.bat` (or run `./Start-Mise-Desktop.ps1` in PowerShell).
*Mise opens immediately in an app window. Any device on the same local Wi-Fi can also connect!*

### 2. Run on Linux / Mac Computer / Laptop
Open a terminal in this folder and run:
```bash
./Start-Mise-Desktop.sh
```

### 3. Install on Android Phone / Tablet (Waiter / Kitchen)
Transfer `Mise-POS-Android-App.apk` to any Android phone or tablet via WhatsApp, Google Drive, or USB cable, and tap to install.

## 🔑 How Organisation Multi-Device Pairing Works

When launching Mise for the first time:
1. Click **"Create New Organisation"** (e.g., *"Kokum House"*).
2. The system automatically creates your organisation and provides **4 Role Access Codes**:
   - 🍳 **Kitchen (KDS):** `KITCH-...` *(For kitchen screens/tablets — orders appear instantly with timers & 86 item toggle)*
   - 📝 **Waiter (Ordering):** `WAITR-...` *(For waiter phones — fast table layout, category search, add to cart)*
   - 💳 **Counter (Billing):** `COUNT-...` *(For counter terminals — GST split, UPI QR, Cash change calc, Invoice issue)*
   - 📊 **Manager (Full Audit):** `MANG-...` *(Full control: Menu editor, Pantry grocery audit, Tax settings, Printer IP config, Day Close)*
3. On any additional phone or tablet, simply tap **"Join Existing Organisation"** and enter your Org ID + the module code to lock the device into that exact role.
